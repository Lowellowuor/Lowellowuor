## Overview

I work at the intersection of **software engineering, data systems, and applied machine learning**. My approach is first-principles and outcome-driven: define the problem precisely, design the simplest architecture that can scale, instrument it, then iterate against real usage.

- **Architecture-first.** Clean Architecture, clear service boundaries, and APIs designed to evolve.
- **Data-driven.** Relational modelling in SQL, with analytics built for real-time decision-making.
- **Applied AI.** NLP and ML integrated into production workflows, not left in notebooks.
- **Ship, measure, improve.** Agile delivery and CI/CD so releases are frequent, safe, and reversible.

## Selected Work

### Enterprise Recruitment Platform
**Problem:** Hiring teams need a structured, searchable way to match talent to roles at scale.
**Approach:** Normalised SQL schema with a CodeIgniter backend and a performance-conscious JavaScript interface.
**Stack:** `SQL` · `CodeIgniter` · `JavaScript`

### Conversational AI Agent
**Problem:** Support teams lose time and users lose patience to repetitive queries.
**Approach:** A Python/Flask agent using NLP to classify intent and automate responses, reducing support latency.
**Stack:** `Python` · `Flask` · `NLP`

### Business Intelligence Dashboards
**Problem:** Decision-makers cannot act on raw, complex datasets.
**Approach:** Query-optimised SQL pipelines feeding real-time dashboards built for concurrent use.
**Stack:** `SQL` · `Python` · `Data Visualisation`

### E-Commerce Front-End
**Problem:** Storefront UX directly drives engagement and conversion.
**Approach:** A responsive, accessible interface in vanilla JavaScript with light/dark theming and no framework overhead.
**Stack:** `HTML` · `CSS` · `JavaScript`

## Engineering Principles

1. **Simplicity scales.** Prefer the simplest design that meets the requirement.
2. **Measure before optimising.** Instrument first; let data guide the work.
3. **Design for change.** Loose coupling and clear interfaces outlast any framework.
4. **Human-first.** The best systems are the ones people actually enjoy using.
